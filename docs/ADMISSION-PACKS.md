# Admission packs (WO-031)

Opinionated intended-use prompts and evidence checklists for three classes:
coding-agent, MCP server, and model/weights.

Packs are scaffolds, not certificates. Team Graph is not live.
Public registry install is not available. No PQC hero claims.

Versioned copies live under ops/admission-packs/v1/.
Runtime source is src/lib/admission-packs.ts (must match JSON).

Select a pack on /assess. Local Operator uses --pack and --list-packs.
See ops/admission-packs/README.md for file map and sample public GitHub URLs.
